# 第一阶段：按钮分类与常用快捷栏

[English](skill-launcher-categories.md) | 中文

Fork 自有的 Skill Launcher 在固定快捷栏下方每次只显示一个分类。已有 Skill 和提示词的插入行为保持不变；未修改任何 Agent 生命周期或 DSH 核心代码。

在 **设置 → 编码按钮 / Skill Launcher** 中：
- 勾选或取消某个分类可以显示或隐藏它的标签；这**不会**禁用对应的 Skill。
- 勾选任意按钮的**固定快捷栏**即可让它常驻快捷栏。固定的按钮不会在分类中重复显示。
- 调整**排序**改变按钮在分类和快捷栏中的顺序。
- 已有**启用**开关用于在所有位置禁用按钮。
- 保存到 Host Settings（带版本校验）或取消以恢复上次保存的状态。

操作文档为 schema 版本 3：它在每个操作上增加可选的布尔字段 `pinned`；版本 2 客户端重建操作时会丢弃未知字段，因此会拒绝版本 3，而不是丢失全部固定设置。版本 1 和版本 2 仍按原样加载。分类显示状态单独存放在 Host Settings 的 `hiddenGroups` 中。包括 Windows 离线部署在内，无需网络。
