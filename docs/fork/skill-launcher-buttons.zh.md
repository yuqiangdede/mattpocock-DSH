# 第一阶段：快捷按钮与「更多」

[English](skill-launcher-buttons.md) | 中文

Fork 自有的 Skill Launcher 在 Composer 上方只显示一行快捷按钮；其余启用的按钮都收在单个「更多」按钮里，点击「更多」展开或收起列表。已有 Skill 和提示词的插入行为保持不变；未修改任何 Agent 生命周期或 DSH 核心代码。

在 **设置 → 编码按钮 / Skill Launcher** 中：
- 勾选按钮的**显示在快捷栏**即可把它直接放进这一行。未勾选的启用按钮只出现在「更多」里。
- 调整**排序**同时改变按钮行和「更多」列表的顺序。
- 使用已有的**启用**开关可以在所有位置关闭按钮。
- 保存到 Host Settings（带版本校验）或取消以恢复上次保存的状态。

操作文档为 schema 版本 3：它在每个操作上增加可选的布尔字段 `pinned`，用于标记直接显示的按钮；版本 2 客户端重建操作时会丢弃未知字段，因此会拒绝版本 3，而不是丢失全部显示设置。版本 1 和版本 2 仍按原样加载。版本 3 文档省略已停用的 `group` 字段，读取方会忽略它；分类显示状态（`hiddenGroups`）不再保存。包括 Windows 离线部署在内，无需网络。
